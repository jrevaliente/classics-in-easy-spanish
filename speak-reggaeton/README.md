# Speak Reggaeton — Reader Companion

**Author:** José Revaliente. **Level:** A1–A2.

**Approved subtitle:** Spanish Slang for Beginners with Online Audio: Puerto Rican Expressions, Real-Life Dialogues, and Latin Music Culture.

**Website:** https://jrevaliente.github.io/classics-in-easy-spanish/speak-reggaeton/

## Contents
- `index.html`: responsive English companion site; 12 audio players, dictionary, flashcards, downloads.
- `data/vocabulary.json`: 122 structured dictionary entries extracted from the author's Google Docs V3.3 working manuscript.
- `data/vocabulary.js`: offline-friendly client-side dictionary data.
- `downloads/`: CSV, TSV (Anki), printable companion and narrative maps.
- `assets/cover-1600x2560.jpg`: cover image to upload manually.
- `audio/`: external audio hosting notes; MP3 files not mirrored.

## Editorial / release checks
- The V3.3 manuscript has a DIFFERENT subtitle and says no audio is included; reconcile before KDP release.
- Link checks on the external audio and exact spoken/written synchronization remain a final editorial QA gate.
- The manuscript and labels are educational; slang varies across countries and contexts.
- This section is separate from other Classics in Easy Spanish content and has not altered the other book folders.

## Uploading the cover
Open `speak-reggaeton/assets` in GitHub and use **Add file → Upload files**, upload `cover-1600x2560.jpg`, then **Commit changes**. GitHub Pages can take time to rebuild. Use the book's exact approved cover.

## Anki import
Import `downloads/speak_reggaeton_a1_a2_anki.tsv` as a UTF-8, tab-separated file. Basic note type, Front / Back / Tags. Header comments communicate the separator and column names. Check mapping before import.

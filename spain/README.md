# SPAIN — Speak Spanish Like a Local (B1–B2)

This folder contains the reader companion and 24 externally hosted audio links for the original teaching book by José Revaliente.

- Web: `index.html`
- Audio index: `audio/tracks.json` (Internet Archive links supplied by the publisher; availability must be checked in browser)
- CSV: `downloads/spain_b1_b2_vocabulary.csv` — 144 chapter expressions sourced from manuscript
- Anki: `downloads/spain_b1_b2_anki.tsv` — import as tab-separated, Front/Back/Chapter; UTF-8
- Flashcards: `downloads/flashcards.html`
- Timeline: `downloads/conflict-timeline.html`
- Map: `downloads/character-conflict-map.html`
- Printable companion: `downloads/printable-reading-companion.html`

## Cover upload

This GitHub connector cannot transmit the binary image that was uploaded in the conversation. **Upload the supplied JPG manually to exactly `spain/assets/cover.jpg`**. The web page has a text fallback until this is done. The image delivered is 1600×2560 pixels, resized from a supplied image of 1280×2048; the source was not genuinely native 1600 pixels wide.

## Size and audio policy

Audio MP3 files are not stored in this repository, to conserve the GitHub Pages 1 GB published-site limit. The `audio/` folder is retained for metadata or later manually managed assets. The root `index.html` of the existing site is updated only to add a link to this new section. No other book section is modified.

# EL CANTAR DE MIO CID — B2 Reader Companion

Original anonymous medieval Castilian work · José Revaliente adaptation.

This companion provides 24 external MP3 chapter links (C01–C24), a curated English vocabulary list, an Anki TSV deck, a narrative conflict timeline, a character relationship map and a print-friendly reading companion.

The full downloadable ZIP created in this conversation also contains the approved cover derivatives and the five-page companion PDF, both requiring manual upload via GitHub's file uploader if absent online.

No PDF/audio files are copied from an external publisher. B2 is an editorial classification; Production Lock and Publication Ready are **not** implied.

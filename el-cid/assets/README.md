# El cantar de mio Cid — cover assets

This folder holds the approved B2 cover derivatives used on the reader companion site.

Required image files (upload separately, without altering the approved design):

- `cover.webp` — web-optimized cover, 680 × 1020 px.
- `cover-high-resolution.png` — high-resolution cover, 2048 × 3072 px.

The site at `../index.html` references these exact paths. The images are not included by this README commit; they must be uploaded as binary files.

# Catalan Folktales in Easy Catalan — BOOK01 companion

Published path: /classics-in-easy-spanish/classics-in-easy-catalan/

This buildless companion contains ten external audio players; 163 contextual glossary entries; synchronized JSON, CSV, TSV and Anki APKG; interactive flashcards; ten story timelines; character/conflict relationship tables; 60 manuscript comprehension questions; separate worksheet and answer-key PDFs; and the supplied original cover.

Source: current native manuscript, Google Docs ID 1Fvpn4NDBU-PbGEEptwKnPAEHcIFI7w0tw-MtZllKpx0, retrieved 17 November 2026. Resource texts are derived from its glossary, stories, comprehension questions and answer key. No manuscript edits were made.

Cover: original PNG is 1024 × 1536, preserved byte-for-byte. The optimized JPEG is used for web display. A higher-resolution source was not supplied.

Audio: Internet Archive collection catalan_folktales_in_easy_catalan. Chapters 7 and 10 use the actual filenames `07 .mp3` and `10 .mp3` (URL-encoded space). Source Audio.txt is retained unchanged in audio/Audio-original.txt. Availability does not certify full listening or word-for-word manuscript synchronization.

Upload the entire classics-in-easy-catalan directory to the main branch root if manual restoration is needed. All required directories already contain their resources. There are no local MP3s to upload.

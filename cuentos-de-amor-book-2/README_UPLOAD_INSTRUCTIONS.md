# Book 2 · GitHub page and download instructions

This folder contains published HTML pages for 24 stories, audio links and two story maps. The PDF, CSV, TSV, JSON and two JPGs can be uploaded from the supplied local ZIP to complete all download links. Place images in `assets/` and the other files in `downloads/` without altering sibling books.

C01–C24 links come from the owner-supplied audio list; recording-to-story matches require playback QA. The 2400×3600 JPG is upscaled from 1024×1536 and is not a press-ready KDP cover.

The browser-printable page currently contains general worksheet prompts; the offline ZIP includes a richer printable HTML containing the exact 72 source comprehension questions.

How to Import the B1 Flashcards

The Anki-compatible TSV contains 137 basic vocabulary cards based on the Spanish retelling of La Navidad en las montañas. The cards are supplementary study aids, not an Anki package (.apkg) or a pre-built deck.

Import into Anki

  1. Download navidad_b1_anki.tsv using the link above.
  2. Open Anki Desktop and select File → Import (wording may vary by version).
  3. Choose the downloaded TSV and confirm the field separator is Tab and the encoding is UTF-8.
  4. Choose a Basic note type with two fields. Map column 1 → Front (Spanish) and column 2 → Back (English meaning).
  5. Map column 3 → Tags, rather than a third text field. Tags identify the book and part (for example Navidad_B1 and Part_IV).
  6. Import and test a few cards: the Spanish entry should appear on the front, the contextual English meaning on the back.

Using the CSV without Anki

The separate Vocabulary CSV contains the same 137 entry/meaning pairs plus the first part in which each entry occurs. It has a header row and is UTF-8 encoded. Open it in a spreadsheet or compatible flashcard tool and filter by part.

Story first: some vocabulary entries refer to events in Part XI. To avoid spoilers, filter or study only parts you have already read. The deck is vocabulary-only: it does not contain MP3 audio or source-text example sentences. See the book for full context and the Spanish/English support translation.

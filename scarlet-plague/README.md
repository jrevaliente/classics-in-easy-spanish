# The Scarlet Plague in Easy Spanish — companion

Public route: /classics-in-easy-spanish/scarlet-plague/
Six Spanish audio links stream from the publisher-supplied Internet Archive collection.
The 53 glossary entries and 18 comprehension questions / model answers are drawn from the current manuscript. Timeline and map are editorial study aids based on that text. No complete narrative is published here.

## Files
- assets/style.css: responsive and print styles
- downloads/scarlet_plague_b1_vocabulary.csv: 53 entries, three columns
- downloads/scarlet_plague_b1_anki.tsv: 53 Spanish → English cards, two fields
- downloads/conflict_timeline.html: chapter timeline, spoilers
- downloads/character_conflict_map.html: characters and relationships, spoilers
- downloads/printable_reading_companion.html: questions, writing space, separately hidden answers
- audio/README.md: external audio hosting reference

Use the browser Print / Save as PDF command for printable HTML. The companion does not claim word-level audio synchronization. MP3 existence and durations were verified against Archive metadata on 2026-11-15; recording-to-manuscript correspondence requires a listening audit.
